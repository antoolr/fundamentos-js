 Práctica DWEC: Fundamentos de JavaScript

Repositorio correspondiente a la práctica de Fundamentos de JavaScript para el módulo de Desarrollo Web en Entorno Cliente (DWEC). 

El proyecto recopila 21 ejercicios divididos en dos bloques de trabajo para consolidar los conceptos básicos de sintaxis, manipulación del DOM, lógica y manejo de arrays/objetos en JavaScript.

Estructura del proyecto

Cada ejercicio está aislado en su propia carpeta con su correspondiente `index.html`, `estilos.css` y `app.js`:

- Bloque A (Ejercicios 01 a 06): Sintaxis básica, variables (`let`/`const`), operadores, interacción básica por consola y eventos DOM sencillos.
- Bloque B (Ejercicios 07 a 21) Funciones, métodos de arrays (`filter`, `reduce`, `split`), algoritmos sencillos y manipulación de cadenas.
- `index.html` (Raíz): Portada principal del proyecto que sirve como desplegable para navegar a cualquiera de los 21 ejercicios subidos.

 Cómo ejecutar los ejercicios

 1. Desde la web (GitHub Pages)
El proyecto se encuentra desplegado y accesible públicamente en la siguiente dirección:
https://antoolr.github.io/fundamentos-js/

Basta con acceder al enlace y pinchar sobre el ejercicio que se desee probar.

 2. En local desde la terminal (Node.js)
Aquellos ejercicios que no dependen del DOM ni de elementos HTML (por ejemplo, lógica con `console.log`) pueden probarse directamente usando Node.js desde la raíz
